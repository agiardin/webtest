# webtest

A simple hello-world web application built with TypeScript and Express.

## Prerequisites

- Node.js (v14 or higher)
- npm

## Installation

```bash
npm install
```

## Usage

### Development Mode

Run the application in development mode with ts-node:

```bash
npm run dev
```

### Production Mode

Build the TypeScript code and run the compiled JavaScript:

```bash
npm run build
npm start
```

## Testing

Open your browser and navigate to `http://localhost:3000` or use curl:

```bash
curl http://localhost:3000
```

You should see "Hello, World!" displayed.

## Project Structure

- `src/index.ts` - Main application file
- `tsconfig.json` - TypeScript configuration
- `package.json` - Project dependencies and scripts
